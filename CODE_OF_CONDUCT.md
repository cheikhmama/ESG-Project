# Code of Conduct

## Our Standards

ESG Toolkit is an open, professional community. All participants are expected to:

- Be respectful and constructive in all communications
- Welcome contributors of all backgrounds and experience levels
- Accept feedback graciously and give it thoughtfully
- Focus on what is best for the project and its users

Unacceptable behaviour includes personal attacks, trolling, public or private
harassment, and any form of discrimination. These will result in removal from
the project.

## Scope

This code of conduct applies in all project spaces — GitHub issues, pull
requests, discussions, and any other venue where you represent this project.

## Enforcement

Report concerns to the maintainers at the repository's GitHub Discussions page
or by opening a private security advisory. All reports will be reviewed and
investigated promptly and confidentially.
